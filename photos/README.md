# Folder Foto

Taruh 5 foto di folder ini dengan nama persis seperti di bawah, biar otomatis
kepasang di game (nggak perlu pilih ulang tiap buka).

| File        | Muncul di          | Caption yang udah nempel                                            |
|-------------|--------------------|---------------------------------------------------------------------|
| `foto1.jpg` | Memory #1 (Stage 1) | "Kamu, matcha, sama tangga itu…"  → foto kamu di tangga bawa matcha  |
| `foto2.jpg` | Memory #2 (Stage 2) | "Kepala kamu nempel di aku…"      → selfie kepala nempel di mobil    |
| `foto3.jpg` | Memory #3 (Stage 3) | "Duo paling absurd sejagat raya…" → selfie monyong berdua            |
| `foto4.jpg` | Memory #4 (Stage 4) | "Kena sinar sore…"                → selfie kena cahaya matahari      |
| `foto5.jpg` | Memory #5 (Stage 5) | "Yang ini aku simpen paling dalem…" → selfie senyum berdua di mobil  |

Format yang didukung: `.jpg`, `.jpeg`, `.png`, `.webp` (juga `.JPG`).
Fotonya paling pas kalau agak potrait (3:4), soalnya dipajang model polaroid.

Kalau nggak mau ribet naruh file: buka gamenya, tekan tombol **📷** di pojok
kanan atas, terus pilih foto langsung dari galeri HP. Foto yang dipilih lewat
situ disimpan di browser HP itu aja dan nggak ke mana-mana.

Caption bisa diubah di `index.html`, cari `const CAPTIONS`.
